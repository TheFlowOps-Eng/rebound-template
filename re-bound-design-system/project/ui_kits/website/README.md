# Re:Bound — Website UI Kit

High-fidelity recreation of the Re:Bound marketing site, faithful to the Figma file `Re_Bound Website.fig`. A click-through prototype across the main marketing surfaces:

- `#home` — hero, method explainer, three-class overview, studio CTA, founder letter, waitlist
- `#classes` — class library filter + expandable class rows
- `#instructors` — team grid with instructor detail
- `#contact` — inline form

## Files

- `index.html` — mounts all screens and lets you navigate via top nav
- `components.jsx` — Nav, Footer, Button, Eyebrow, shared pieces
- `HomeScreen.jsx` — home page
- `ClassesScreen.jsx` — classes library
- `InstructorsScreen.jsx` — team page
- `ContactScreen.jsx` — contact form page

## How to run

Open `ui_kits/website/index.html` in the preview. Click nav links to switch screens.
